# ⚫ Modding Guide — Obsidian Protocol

This document defines how modding will work in Obsidian Protocol: Autonomous Warfare.  
It is a foundation for future tools, editors, and community content.

## 🧩 Overview
Obsidian Protocol is designed for modular content. Factions, units, abilities, maps, campaigns, and AI personalities can be added or modified without touching core systems.

Modding is built around:
- JSON-style definitions  
- Modular Unity components  
- Asset bundles  
- Editor tools (future)  
- Strict separation between core logic and content packs

## 📜 Guidelines
- Keep mods modular  
- Avoid editing core files  
- Document custom components  
- Test before publishing  
- Follow naming conventions
