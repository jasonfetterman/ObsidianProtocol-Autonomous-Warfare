# ⚫ Obsidian Protocol — Development Roadmap

This roadmap outlines the planned development phases for Obsidian Protocol: Autonomous Warfare. Each phase builds toward a fully autonomous RTS experience with large-scale battles, intelligent AI, and a modular ecosystem for players and creators.

---

## 🔹 Phase 1 — Core Systems (Current)
Foundational systems required for autonomous RTS gameplay.

### AI & Autonomy
- Autonomous squad behavior
- Tactical decision-making (flanking, breaching, suppression)
- Intent-based command system
- Region memory & battlefield awareness

### RTS Core
- Modular faction architecture
- Unit framework (Air, Ground, Sea, Command, Experimental)
- Resource & construction fundamentals
- Basic siege & breach logic

### Performance
- Pooling & batching
- Async operations
- Optimized map streaming

---

## 🔹 Phase 2 — Vertical Slice
A playable, internal slice demonstrating core gameplay.

### Gameplay
- Playable skirmish scenario
- Two prototype factions
- Base building + tech progression
- Dynamic battlefield interactions

### Presentation
- Early VFX & SFX
- Early UI/UX
- Basic HUD & command interface

### Testing
- Internal playtesting
- Balance passes
- AI behavior tuning

---

## 🔹 Phase 3 — Public Reveal
Preparing Obsidian Protocol for public visibility.

### Marketing
- Gameplay trailer
- Steam page draft
- Feature overview graphics

### Community
- Community testing build
- Feedback-driven iteration
- Expanded AI behaviors

### Content
- Additional units & structures
- More battlefield interactions
- Improved UI/UX

---

## 🔹 Phase 4 — Expansion & Modding
Opening the ecosystem for creators and long-term growth.

### Tools
- Faction creation tools
- Campaign scripting system
- Map editor
- Modding documentation

### Systems
- Advanced AI personalities
- Expanded tech trees
- Additional factions

### Community
- Modding support
- Community showcase
- Long-term content updates

---

## 🔮 Long-Term Vision
Obsidian Protocol aims to evolve into a large-scale autonomous warfare simulator featuring:

- Evolving AI commanders  
- Full campaign mode  
- Massive autonomous battles  
- Cinematic RTS experience  
- Cross-genre expansion  
- Deep modding ecosystem  

The battlefield should feel alive — every match, every squad, every decision.
