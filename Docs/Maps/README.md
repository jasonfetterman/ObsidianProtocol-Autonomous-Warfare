# Map guide

This folder contains readable Markdown versions of the 50 map definitions. Headings and spacing are intentionally
used for comfortable reading at normal document size.

The detailed source specifications remain preserved under `Docs/Design/Source PDFs/` and
`Docs/Design/Extracted Text/`. The corresponding structured map data remains under
`Assets/Data/Maps/MapDefinitions/`.
