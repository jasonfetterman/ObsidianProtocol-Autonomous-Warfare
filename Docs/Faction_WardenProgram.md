# ⚫ Faction Overview — The Warden Program

The Warden Program is Black Steel Innovations’ autonomous warfare division, deploying a full-spectrum fleet of air, ground, sea, command, and experimental units. It represents the primary playable faction for the first release of Obsidian Protocol.

## Mission Profile
Precision. Autonomy. Tactical superiority.

The Warden Program focuses on battlefield awareness, intelligent decision-making, and coordinated autonomous operations across every environment — air, land, and sea.

## Strengths
- Massive recon capability  
- Highly autonomous squads  
- Strong command units  
- Deep experimental tech tree  
- Excellent battlefield awareness  

## Weaknesses
- High resource cost  
- Requires strategic intent  
- Vulnerable to swarm factions  

## Playstyle
- Establish recon dominance  
- Deploy autonomous squads  
- Use intent zones to guide behavior  
- Leverage command units for battlefield control  
- Deploy experimental units to break stalemates

## Fleet Composition
- **Air Units:** Recon, strike, uplink, scanning, support  
- **Ground Units:** Armor, APCs, logistics, demolition  
- **Sea Units:** Patrol, recon, detection, heavy destroyers  
- **Command Units:** AI cores, uplinks, strategic controllers  
- **Experimental Units:** Stealth, phase-shift, prototypes
