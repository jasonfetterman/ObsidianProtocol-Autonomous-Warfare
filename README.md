🎮 Overview
Obsidian Protocol is a futuristic real‑time strategy game built around autonomous squads, dynamic battlefields, and intent‑based commanding.
Instead of micromanaging every unit, you set goals — squads interpret your intent and act intelligently.

Built for scale.
Built for modding.
Built for players who crave emergent, cinematic warfare.

⭐ Why People Will Want This Game
Squads flank, retreat, breach, suppress, and coordinate without micromanagement

Fog‑of‑war, destructible cover, elevation, visibility cones, suppression zones

AI behaves like a commander — multi‑angle assaults, breach logic, siege tactics

Modular systems for factions, units, tech trees, abilities, campaigns

Optimized for massive autonomous battles

Obsidian Protocol isn’t just an RTS — it’s a living battlefield simulator.
